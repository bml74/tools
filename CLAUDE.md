# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

This is a tools repository containing two main skill systems:

- **`qr/`** – QR code-based secure code transfer system
- **`hooks/`** – Claude Code hooks and integrations

For detailed information on each skill, see the CLAUDE.md and documentation in each folder.

## Folder Structure

Each folder contains:
- **CLAUDE.md** – Brief overview and references
- **docs/** – Detailed documentation (referenced in CLAUDE.md to keep token usage low)
- **Source code** – Implementation files

See [[qr-skill]] and [[hooks-skill]] for folder-specific guidance.
